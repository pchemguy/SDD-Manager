# SDD Manager

SDD Manager is an Agent Plugin for specification-driven development in Git repositories. `sdd-orient` prepares a read-only project handoff, `sdd-conventions` provides reusable criteria, `sdd-design` guides exploration and structure, `sdd-specify` defines required behavior and acceptance, `sdd-plan` develops delivery strategy and physical layout, and `sdd-tasks` derives and tracks executable work.

The document sequence is project brief, architecture, decomposition, specification, delivery plan and layout, then executable tasks. `ARCHITECTURE.md`, `DECOMPOSITION.md`, `SPEC.md`, `PLAN.md`, and `layout.md` may each have focused children. Implementation, recovery, and orchestration remain planned capabilities.

See the [capability map](docs/dev/CAPABILITY-MAP.md) for ownership and implementation status.
