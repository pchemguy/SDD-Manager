# SDD Manager

SDD Manager is an Agent Plugin for specification-driven development in Git repositories. `sdd-orient` prepares a read-only project handoff, `sdd-conventions` provides reusable criteria, `sdd-design` guides exploration and structure, and `sdd-specify` defines required behavior and acceptance.

The document sequence is project brief, architecture, decomposition, specification, delivery plan, and executable tasks. `ARCHITECTURE.md`, `DECOMPOSITION.md`, and `SPEC.md` may each have focused children. Planning, implementation, recovery, and orchestration remain planned capabilities.

See the [capability map](docs/dev/CAPABILITY-MAP.md) for ownership and implementation status.
