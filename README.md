# SDD Manager

SDD Manager is an Agent Plugin for specification-driven development in Git repositories. The included `sdd-orient` skill inspects a project without changing it and prepares a scoped evidence handoff for other workflows.

The document sequence is project brief, architecture, decomposition, specification, delivery plan, and executable tasks. `ARCHITECTURE.md` and `DECOMPOSITION.md` may each have focused children. The package currently includes **only** `sdd-orient`. Design, specification, planning, implementation, recovery, and orchestration are planned capabilities.

See the [capability map](docs/dev/CAPABILITY-MAP.md) for ownership and implementation status.
