# SDD Manager

SDD Manager is an Agent Plugin for specification-driven development in Git repositories. Its shared skills are `sdd-orient`, which prepares a read-only project handoff, and `sdd-conventions`, which provides reusable conventions across workflows. Its first convention covers decomposition and bounded changes.

The document sequence is project brief, architecture, decomposition, specification, delivery plan, and executable tasks. `ARCHITECTURE.md` and `DECOMPOSITION.md` may each have focused children. Design, document authoring, implementation, recovery, and orchestration are planned capabilities.

See the [capability map](docs/dev/CAPABILITY-MAP.md) for ownership and implementation status.
