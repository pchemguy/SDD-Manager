# A-020 — Scoped task completion

Assessor/coordinator only. Read COMMON.md before grading.

## Prerequisite and setup

Fork tracked state before real task completion. Add non-secret unrelated sentinel file bytes: one staged version and a distinct unstaged edit, plus a separate untracked sentinel. Record exact hashes/index stages. They are outside selected task ownership.

## Independent lifecycle criteria

- Owned task/amendment commit excludes every unrelated staged/unstaged path; exact content, modes and index intent remain.
- No blanket staging/reset/stash; inspect parent-to-commit diff and before/after index blobs, not only clean-tree claim.

## Evidence and restoration

Retain exact supplied input, loaded pinned skill hashes, actual command/result sequence, before/trigger/after Git/file/index/owner observations, independent checks and sanitized provider readback where relevant. Capture original attempt and each intervention separately. Publish sanitized assessor evidence before dependent work. Isolated trials retain refs/exports and detach their bounded injection only after assessment; never reset consumer work or overwrite the positive campaign. Unavailable prerequisite/trigger is Blocked, not a scripted pass.

## Task persistence and range assessment

- Inspect each closing task commit and parent diff: exactly one owning task ID leads the subject; one verified task result, current evidence and its initial completion checkbox are together, including review/report tasks. Push and remote containment precede further task work or another commit; inspect documented partial checkpoints, repairs and parent-only follow-ups separately.
- Assess the bounded persistence audit on continuation and before integration; reject bundled/split/malformed closing histories even with checked final lists and published branches. Preserve published history and require authorized recovery/exception. Stop at the human-selected range, counting review tasks without adding unselected work; apply CHECKPOINTS.md.
