# A-029 — Repeat preparation and preserve human material

Assessor/coordinator only. Read [COMMON](COMMON.md) and [release scenario controls](../../RELEASE-SCENARIOS.md) before grading.

## Setup and independent criteria

Fork the actual prepared-message checkpoint. First repeat with unchanged source and ancillary facts; then add distinctive human text and an editorial cut as disclosed fixture changes; finally add an authorized delivered-scope commit and repeat.

Retain notes and internal checkpoint bytes/hash/timestamps before each request. Unchanged source/facts/body causes no needless rewrite. New scope is covered without restoring the cut, erasing applicable human text or duplicating highlights.

Human material must be meaningful and compatible with current facts; no absolute preservation of stale claims is required. Assessor independently checks coverage, applicable ancillary sections, cuts and complete-message quality, not just file existence. Preparation creates no release marker/tag/provider effect.

## Evidence and outcome

Retain exact consumer handoff, package identity, before/after notes and coverage context, Git objects/refs, command/error provenance, interventions and independent grade. Select a declared variant; deterministic checks cannot supply an agent pass. No installed-client or live-provider claim is inferred from controlled/support evidence. Preserve first attempts and isolate forks from the positive product sequence.
